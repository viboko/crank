# Pockets: hand-written code that survives

Generated files usually get overwritten, but a template can mark a
region as yours with a pocket: `// name [` to `// ]` around whole
lines, or `/* name [ */` to `/* ] */` within one. On every run after the
first, crank reads the previous output (it finds it through
`.crank.manifest`) and keeps whatever you wrote inside each pocket.

Here `client.js` was generated earlier and then edited by hand inside
its `custom-headers` pocket and its inline `timeout` pocket, so this run
keeps those edits while updating `baseUrl` from `api.yaml`.

The playground re-runs crank after every edit, to any file. Try editing
`client.js`: a change inside a pocket stays, but anything outside one
is put straight back, just as the next real run would.

## `.crank`

```yaml
taskGroups:
  - name: client
    object: api.yaml
    tasks:
      - template: client.js.tera
        output: client.js
```

## `api.yaml`

```yaml
name: Orders
baseUrl: https://api.example.com/v2
```

## `client.js.tera`

```text
// Generated by crank from api.yaml.
export class {{ name }}Client {
  constructor() {
    this.baseUrl = "{{ baseUrl }}";
    this.timeout = /* timeout [ */ 5000 /* ] */;
    this.headers = {
      // custom-headers [
      // ]
    };
  }
}
```

## `client.js`

```text
// Generated by crank from api.yaml.
export class OrdersClient {
  constructor() {
    this.baseUrl = "https://api.example.com/v1";
    this.timeout = /* timeout [ */ 30000 /* ] */;
    this.headers = {
      // custom-headers [
      "X-Team": "checkout",
      // ]
    };
  }
}
```

## `.crank.manifest`

```yaml
version: 1
taskGroups:
  client:
  - client.js
```

## Output

```text
Generated 1 file
  - client.js (modified)
```
