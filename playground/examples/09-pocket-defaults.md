# Pockets with default text

A pocket doesn't have to start out empty. Whatever the template puts
between its markers is its default: written the first time crank
generates the file, and kept only until you edit it. From then on
crank keeps your version instead.

Here `server.js` hasn't been generated yet, so this first run writes
both pockets' defaults: a sample `/health` route in `routes`, and
`3000` in the inline `port` pocket. Try replacing the sample route
with your own, then changing the default in `server.js.tera`: your
route stays. Delete `server.js` and the defaults come back.

## `.crank`

```yaml
taskGroups:
  - name: server
    object: service.yaml
    tasks:
      - template: server.js.tera
        output: server.js
```

## `service.yaml`

```yaml
name: inventory
```

## `server.js.tera`

```text
// Generated by crank from service.yaml.
```
