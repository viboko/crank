# Other comment styles

crank's built-in pocket markers, `// name [` and `/* name [ */`, are
comments in C-like languages, but not in Python, SQL or YAML. This
project is mostly Python, so `.crank` lists `#` markers in its
`pocketMarkers`, replacing the built-in ones for every template. Each
marker is literal text with a `{name}` slot where the pocket's name
goes.

Replacing the built-in markers matters in Python, where `//` is floor
division: `rows // PAGE_SIZES[0]` would otherwise read as the start of
a pocket called `PAGE_SIZES`. Try deleting `pocketMarkers` from `.crank`
to see crank report that pocket as never closed.

`schema.sql` is the odd one out: `#` isn't a comment in SQL. So its
template lists its own markers in a `{#- crank: ... -#}` header at its
very start, which win over the ones in `.crank`. Tera skips comments, so
the header never reaches the output.

`models/user.py` and `schema.sql` were generated earlier, and someone
added a method and an index inside their pockets. Both survive this run.
`.crank.manifest` records the markers each file was written with, so
crank still finds old pockets after the markers change.

## `.crank`

```yaml
pocketMarkers:
  - start: '# {name} ['
    end: '# ]'
taskGroups:
  - name: models
    array: app.yaml#models
    tasks:
      - template: model.py.tera
        output: "models/{{ name }}.py"
  - name: schema
    object: app.yaml
    tasks:
      - template: schema.sql.tera
        output: schema.sql
```

## `app.yaml`

```yaml
models:
  - name: user
    fields: [id, email]
  - name: order
    fields: [id, user_id, total]
```

## `model.py.tera`

```text
# Generated by crank from app.yaml.
PAGE_SIZES = [20, 50]


class {{ name | capitalize }}:
    FIELDS = [{% for field in fields %}"{{ field }}"{% if not loop.last %}, {% endif %}{% endfor %}]

    @staticmethod
    def pages(rows):
        return rows // PAGE_SIZES[0]

    # methods-{{ name }} [
    # ]
```

## `schema.sql.tera`

```text
{#- crank:
  pocketMarkers:
    - start: '-- {name} ['
      end: '-- ]'
-#}
-- Generated by crank from app.yaml.
{% for model in models %}
CREATE TABLE {{ model.name }}s (
{%- for field in model.fields %}
    {{ field }} TEXT{% if not loop.last %},{% endif %}
{%- endfor %}
);
{% endfor %}
-- indexes [
-- ]
```

## `models/user.py`

```text
# Generated by crank from app.yaml.
PAGE_SIZES = [20, 50]


class User:
    FIELDS = ["id", "email"]

    @staticmethod
    def pages(rows):
        return rows // PAGE_SIZES[0]

    # methods-user [
    def domain(self):
        return self.email.split("@")[1]
    # ]
```

## `.crank.manifest`

```yaml
version: 1
taskGroups:
  models:
  - path: models/user.py
    pocketMarkers:
    - start: '# {name} ['
      end: '# ]'
  schema:
  - path: schema.sql
    pocketMarkers:
    - start: '-- {name} ['
      end: '-- ]'
```
