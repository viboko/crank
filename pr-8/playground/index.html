crank playground

Render YAML data through Tera templates with a .crank file, and see the generated files as you type.

    Files

    Edit any file and crank re-runs, just as if you'd run it again. Files it generated are regenerated each time, except inside a pocket.

    generated error Tab indents · Esc then Tab leaves the editor

    crank runs here as WebAssembly, entirely in your browser — nothing you type leaves this page. The output and generated files are exactly what the crank command prints and writes for the same files. Visits are counted, cookie-free, with GoatCounter.
